# Share a live review on the local network

The workstation serves one captured comparison over HTTP on a selected LAN or studio VPN address. A random link grants access until sharing stops. Anyone with the link can view the review and save a decision. SceneScout shows source paths and authored evidence just as it does in the standalone report.

The browser edits finding notes and flags, review notes, and the decision. The desktop displays them as read-only while sharing is active. Submissions based on an older revision are rejected so an older tab cannot overwrite a newer save. SceneScout applies edits to the current comparison and marks the review unsaved. The existing **Save review** action persists the result.

Stopping sharing, closing SceneScout, or invalidating the comparison ends the session and revokes the link. Sharing uses the comparison evidence captured at startup. Thumbnail pairs captured later appear on the same link on reload and leave the edit revision unchanged. A changed comparison needs a new link.
