# Local publish sign-off

Compare classifies each finding as structural, animation or dependency. OpenUSD composition arcs identify effective reference and payload targets when USD can associate the arc with the introducing opinion. The resolver runs in the stage's context and anchors the authored identifier to its authoring layer. Resolver results, authored list edits, and effective arcs are shown independently. OpenUSD composition errors produce diagnostic findings. Unloaded payloads contribute coverage findings and their contents stay outside the comparison.

Snapshot inspection streams hierarchy rows before reading authored evidence and attribute summaries. Separate background jobs scan snapshots and compare the stage pair. Generation checks discard superseded results. Cancellation is cooperative around USD calls. A resolver or composition call already inside USD may still need time to return.

Saved reviews use versioned local JSON with the original stage paths and load rules. They capture the queue, values for Stage A and Stage B, evidence, reviewed flags, open issues, notes, decision and review position. The saved review is readable with the source stages offline. Resume recomposes the original paths using the saved load rules and alignment. A changed finding set or coverage returns the decision to Pending. This validates the compared results under the current coverage. It does not fingerprint the USD files.

The decision defaults to Pending. Reviewers can record Approved or Changes requested. The standalone HTML contains the decision, coverage, key changes, open issues and supporting evidence without external assets.
